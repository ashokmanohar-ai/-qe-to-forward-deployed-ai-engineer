## How to use resources

For every resource, create one output:

- concept map;
- reproduced example with changed inputs;
- failure you introduced and diagnosed;
- decision record applying it to the capstone;
- test or evaluation derived from it;
- two-minute explanation for a customer.

If a resource does not change your code, decision, experiment, or explanation, it is probably passive consumption.
