# Live FDE Solution Studio

**Live demo:** https://fde-solution-studio.vercel.app

## What the demo proves

The customer brief is editable. From that input, the application generates and updates discovery findings, requirements, architecture components, PoC exit criteria, risks and a production-readiness score.

```text
Customer brief → discovery → requirements → architecture → PoC gates → risks → production readiness
```

The heuristics are intentionally transparent and local so the recruiter can change the problem and see the delivery evidence change without an API key.

## Why this matters for FDE roles

The demo focuses on customer-to-production thinking rather than model prompting alone: problem framing, measurable success criteria, integration/security/NFR concerns, prototype gates, risk ownership and rollout readiness.

Use this repository for the broader QE-to-FDE engineering journey and the live studio for the short interactive walkthrough.

## Integrity statement

The public app is a deterministic delivery-planning simulator, not a claim that an LLM autonomously designed a production architecture. In real delivery, customer discovery, architecture review, security, integration testing and operational evidence remain human-governed engineering activities.
